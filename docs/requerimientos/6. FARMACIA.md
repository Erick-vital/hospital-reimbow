**Módulo de Farmacia**

**1. Objetivo**

El módulo de Farmacia será responsable de gestionar el ciclo completo del medicamento dentro de Reimbow HIS, desde su recepción y almacenamiento hasta su dispensación, devolución, ajuste y trazabilidad hacia el paciente.

Deberá integrar funciones clínicas, logísticas y administrativas relacionadas con medicamentos.

Sus objetivos principales serán:

- Favorecer el uso seguro de medicamentos.

- Mantener inventarios confiables.

- Controlar lotes y caducidades.

- Gestionar prescripciones.

- Registrar dispensaciones.

- Mantener trazabilidad por paciente.

- Controlar medicamentos de manejo especial.

- Reducir errores de medicación.

- Detectar problemas de disponibilidad.

- Integrarse con Médico y Enfermería.

- Mantener evidencia de todos los movimientos.

**2. Principios del módulo**

Farmacia deberá diseñarse bajo los siguientes principios:

- Seguridad del paciente.

- Trazabilidad completa.

- Identificación correcta.

- Prescripción validada.

- Control de inventarios.

- Control por lote.

- Control de caducidades.

- Principio FEFO cuando corresponda.

- Separación de funciones.

- Auditoría.

- Registro cronológico.

- Disponibilidad.

- Prevención de errores.

- Control de medicamentos de alto riesgo.

- Control reforzado de medicamentos sujetos a regulación especial.

- Integración clínica.

- Conciliación entre inventario físico y electrónico.

**4. Farmacia vs. Almacén**

Deberán separarse conceptualmente.

**Farmacia**

Gestionará principalmente:

- Medicamentos.

- Prescripciones.

- Dispensaciones.

- Lotes de medicamentos.

- Caducidades.

- Devoluciones.

- Medicamentos controlados o de manejo especial.

- Existencias farmacéuticas.

- Validación farmacéutica.

- Trazabilidad hacia pacientes.

**Almacén**

Gestionará principalmente:

- Material de curación.

- Insumos.

- Consumibles.

- Material administrativo.

- Otros productos institucionales.

Podrán compartir una infraestructura común de inventarios.

**6. Medicamento vs. presentación**

No deberá almacenarse simplemente:

Paracetamol

porque pueden existir múltiples presentaciones.

Ejemplo:

Paracetamol 500 mg tableta

Paracetamol 750 mg tableta

Paracetamol 1 g/100 mL IV

Paracetamol 100 mg/mL gotas

Cada presentación deberá tener un identificador diferente.

**8. Medicamentos LASA**

El sistema deberá permitir identificar medicamentos:

Look-Alike / Sound-Alike

LASA

es decir, medicamentos con apariencia o nombre semejante que puedan favorecer errores.

Podrá mostrarse una advertencia durante:

- Recepción.

- Almacenamiento.

- Dispensación.

- Prescripción.

- Administración.

La alerta deberá diseñarse evitando fatiga de alertas.

**9. Medicamentos de alto riesgo**

El catálogo permitirá marcar:

⚠ MEDICAMENTO DE ALTO RIESGO

Las reglas asociadas podrán incluir:

- Almacenamiento diferenciado.

- Validación adicional.

- Doble verificación.

- Restricciones de acceso.

- Trazabilidad reforzada.

- Alertas clínicas.

El catálogo deberá ser configurable por institución.

FAR-RF-011

El sistema deberá registrar dispensaciones relacionadas con paciente, prescripción y lote.

El sistema deberá permitir dispensaciones parciales.

El sistema deberá registrar motivos de no surtimiento.

FAR-RF-014

FAR-RF-017

El sistema deberá generar alertas de caducidad.

El sistema deberá permitir bloquear lotes ante retiros o alertas.
